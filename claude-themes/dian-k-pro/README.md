# Dian K Pro, thème pour Claude

Thème noir et or aux couleurs de Dian K Pro, pour les applications Claude de bureau et mobile.

- **Couleurs** : noir chaud et or (#E3B34C) la nuit, papier ivoire le jour ; grays teintés, rôles (erreur, succès, alerte) conservés.
- **Fond animé** : graines de lumière dorées qui montent lentement et lignes de circuit, reprises du « D » du logo, qui s'allument tour à tour. Placé dans les coins, loin du texte et du champ de saisie ; recomposé sur téléphone.
- **Interactif** (application de bureau) : un halo doré suit le pointeur, et chaque clic envoie un anneau d'or qui s'éteint en moins d'une seconde.
- **Son** (application de bureau, après avoir touché le haut-parleur dans la barre de titre) : ambiance de kora en ré mineur, notes discrètes à l'envoi, à la fin d'une réponse et au clic sur le fond.
- **Messages** : titres à empattements, bulles sobres à fin liseré doré.

Respecte « Réduire les animations » : le fond s'affiche alors immobile. Le terminal et les éditeurs n'affichent pas les thèmes.

## Installation

Dans une session Claude Code, au terminal :

```
/plugin install dian-k-pro --marketplace DianKPro-crypto/nis-strategy-app
```

Répondez `y` pour ajouter la source, puis choisissez la portée « utilisateur » pour l'avoir dans toutes vos sessions.

Depuis un shell :

```
claude plugin install dian-k-pro --marketplace DianKPro-crypto/nis-strategy-app
```

Dans l'application de bureau, où `/plugin` ne fonctionne pas : cliquez sur **+** à côté du champ de saisie, puis **Plugins**, **Add marketplace** avec `DianKPro-crypto/nis-strategy-app`, puis **Add plugin**.
